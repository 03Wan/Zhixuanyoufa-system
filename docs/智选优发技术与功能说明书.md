# 智选优发系统技术与功能说明书

> 用途：比赛成果展示、队员协作与指导老师审阅
> 系统定位：面向高频上新的跨境电商团队，提供多平台 Listing **发布前审校、优化、复核、审批与结果追踪**的一体化工作台。

## 1. 项目概述

跨境电商商品在上架前通常需要同时处理标题、卖点、详情页、图片、目标语言、平台规则和团队审批等事项。传统方式依赖多人分散校对，容易出现规则遗漏、改稿不可追溯、不同站点重复沟通等问题。

智选优发将上述工作组织为可追踪的流程：

```text
选择发布场景 → 导入/生成商品素材 → 发布前审校 → 修改或人工复核 → 发布决策 → 发布结果回填与分析
```

系统不是单纯的 AI 文案工具。AI/规则能力用于辅助生成和识别风险，最终以“发布决策”和“复核记录”帮助团队完成可审计的上架协作。

## 2. 面向对象与使用场景

| 使用角色 | 典型工作 |
| --- | --- |
| 运营人员 | 创建任务、选择站点、提交素材、处理修改建议、导出报告 |
| 设计人员 | 配合维护标题、卖点、详情页及图片相关素材 |
| 复核人员 | 审查高风险任务、给出退回原因或审批结论 |
| 企业管理员/管理人员 | 管理组织、套餐、规则、成员与经营看板 |
| 系统管理员 | 管理全局企业、模型连接、规则库和系统日志 |

适用场景包括新品上架、多平台同步发布、活动素材发布前检查、历史 Listing 复审和团队合规协作。

## 3. 功能说明

### 3.1 公开网站

公开网站承担产品介绍与试点获客职责，提供：首页、产品能力、适用平台、解决方案、套餐价格和关于项目等页面。

- 首页明确产品对象、发布前审校价值、五步工作流和共创计划。
- 适用平台页以覆盖矩阵展示平台、国家/站点、语言、类目和支持状态，区分“已验证、测试中、规划中”。
- 套餐页同时展示正式价格与限量共创价，避免将共创优惠表达为永久低价。
- 关于项目页说明项目边界、建设路径、合作方式及已上线/测试中/规划中的能力。

### 3.2 生成跨境素材

“生成跨境素材”位于工作台左侧“发布任务”分组首位。用户填写商品名称、品类、平台、国家/站点、目标语言和核心卖点后，系统生成可编辑的：

- 商品标题
- 核心卖点
- 详情文案
- 广告语
- 主图/场景图提示词

生成后的内容可一键带入“创建审校任务”。该路径把“生成”置于“审校”之前，避免生成内容绕过平台、市场和品类规则检查。

> 当前 OCR 与图片生成在页面上明确标记为待配置视觉能力后启用；未接入时不会伪装成可用能力。

### 3.3 发布前审校任务

用户可新建单条或批量导入任务，按以下信息建立审校场景：

- 平台、具体国家/站点、目标语言和商品品类
- SKU、商品名称和发布目的
- 标题、卖点、详情文案、广告语、视频脚本
- 主图和场景图 URL 或本地上传图片

任务提交后由系统执行审校，输出风险等级、问题原因、规则依据、推荐修改稿和发布决策。支持保存草稿、提交审校、提交人工复核等动作。

### 3.4 审校结论、修改与人工复核

审校结果页优先展示发布决策与必须修复的问题。对单个问题可执行：采用修改、忽略并说明、标记已修复、提交复核，并保留修改前后差异。

当任务需要人工判断时，进入“人工复核”。复核人员可查看商品信息、原始素材、系统结论和规则证据，完成审批或退回。系统保留负责人、处理状态和审批历史，形成团队协作记录。

### 3.5 规则与模板

规则库集中维护以下类型的规则：

- 平台规则：如 Listing 信息完整性、禁止或限制商品、宣传表达要求。
- 市场文化规则：不同国家/站点的语言、表达和敏感事项。
- 品类规范：服饰、美妆、3C、家居等类目的特定检查项。

每条规则可记录来源、适用平台/国家/类目、版本、生效时间、最近校验时间、测试样例与变更记录，以便复核结论可追溯。

### 3.6 企业、套餐与数据分析

- 企业组织：维护平台方、客户企业及其行业、联系人、目标市场、套餐和服务状态。
- 套餐中心：覆盖免费版、Starter、Growth、Pro 和 Enterprise，并展示模型包、人工风险抽检和 API 验证等增值服务。
- 成效分析：优先展示任务完成量、平均处理时长、首发通过率、人工复核率、建议采用率和系统建议推翻率。
- 发布结果回填：记录发布状态、发布时间、平台 Listing ID、首发是否通过及驳回原因，为后续分析提供数据基础。

### 3.7 模型服务配置

系统管理员可以在“模型配置”中选择 OpenAI、Claude、Gemini、DeepSeek、Kimi、MiniMax、通义千问、智谱、Groq、Mistral、OpenRouter 或“自定义供应商”。

- 支持填写 API 地址、密钥、可选模型标识并验证连接。
- 页面默认使用“供应商当前可用模型”的表达，避免前端固化过期模型版本。
- 自定义供应商可接入兼容 API 的模型服务。
- API Key 仅以安全配置方式保存，页面不回显明文密钥。

## 4. 技术架构

```text
浏览器（Vue 3 + TypeScript + Vite）
        │ HTTPS / REST API
        ▼
服务端（NestJS）
        │ Prisma ORM
        ▼
PostgreSQL（Supabase） ── 对象存储（商品图片等）
        │
        └── 可选：大模型/视觉服务供应商 API
```

| 层级 | 技术选型 | 职责 |
| --- | --- | --- |
| 前端 | Vue 3、TypeScript、Vite、Vue Router、ECharts、Lucide | 页面交互、权限菜单、审校工作流、图表与响应式界面 |
| 后端 | NestJS、JWT、Passport、class-validator | REST API、身份认证、权限校验、业务流程和日志 |
| 数据访问 | Prisma ORM | 数据模型、迁移、查询和事务 |
| 数据服务 | PostgreSQL / Supabase、Storage | 业务数据、规则、任务、报告及图片资源 |
| 部署 | Vercel、GitHub、Cloudflare DNS | 前后端部署、源代码托管、域名解析 |

## 5. 数据与安全设计

- 使用 JWT 进行登录态管理，并基于角色控制工作台菜单和路由访问。
- 任务、素材版本、审校结论、人工复核和发布结果关联保存，保证过程可追踪。
- 模型密钥不在页面明文展示，也不应提交至 Git 仓库。
- 数据库结构通过 Prisma migration 版本化管理，发布时先执行迁移再部署服务。
- 公共网站只展示可核验的支持范围；规划能力明确标注，避免与已上线功能混淆。

## 6. 比赛演示建议

建议按照以下顺序向评委演示：

1. 在公开首页说明目标用户和“发布前审校”定位。
2. 打开适用平台页，展示支持状态矩阵与规则更新信息。
3. 登录工作台，进入“生成跨境素材”，填写目标市场与语言并生成初稿。
4. 将初稿带入“创建审校任务”，提交发布前审校。
5. 在“审校结论”查看问题、依据、修改建议与发布决策。
6. 将高风险任务提交至“人工复核”，展示审批记录。
7. 查看规则库、套餐与成效分析，说明系统如何形成长期数据闭环。

## 7. 本地运行与部署

### 本地开发

```bash
# 前端
cd frontend+
npm install
npm run dev

# 后端
cd backend
npm install
npm run start:dev
```

前端默认地址为 `http://127.0.0.1:4173`。后端需配置数据库连接和 JWT 环境变量；详细配置见 [deployment-vercel-supabase.md](deployment-vercel-supabase.md)。

### 生产部署

- 前端 Vercel 项目根目录：`frontend+`
- 后端 Vercel 项目根目录：`backend`
- 前端生产域名：`https://www.paperhelper.fun`
- 后端生产域名：`https://api.paperhelper.fun`

部署顺序：数据库迁移 → 后端部署并验证 API → 前端部署 → 登录与主流程回归验证。部署变量由 Vercel 项目环境变量管理，严禁提交数据库连接串、JWT 密钥或模型服务密钥。

## 8. 项目成果总结

智选优发以跨境商品上架前的真实协作为核心，将素材生成、场景配置、规则审校、人工复核、发布决策和结果回填组织为一条可复用的产品路径。该设计既能支撑比赛成果展示，也为后续接入更多平台规则、视觉能力、ERP/API 和效果数据提供了可扩展基础。
